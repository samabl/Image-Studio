v0.2.10 修复重复评审、Goal 图片验收中断和 Android 长时间锁屏时的重试停滞。

- 同一批图片在本轮执行中复用真实评审结果，避免重复请求和重复评审面板。Goal 统一在 `review_goal` 中验收最新全部最终图片及完整答案，成图后不再额外自动评分。
- Goal 提交漏图、旧图或多余图片时返回完整的最新图片 ID，继续修正验收，不再显示为执行失败，也不因此重新生图。
- Android 对话和评审的重试等待改为 Rust 原生计时，修复隐藏 WebView 的 JavaScript 定时器停滞导致锁屏任务卡住的问题。流式请求等待响应头和 JSON 回退读取也增加原生响应期限。
- 监测 Android 默认网络、网络挂起及系统后台联网限制；发送前等待可用状态，等待过程中可以取消。设置页显示联网和后台保护状态，任务仍由前台服务与可续期唤醒锁覆盖。
- 网络错误保留底层 DNS、TLS 或断连原因并移除请求 URL。修复原生 429/503 状态码未触发自动重试的问题；鉴权和配置错误立即结束。
- 评审、参考图编辑和蒙版读取必须使用实际图片文件，缺失或越界不再以透明占位图替代。历史瘦身保留没有磁盘副本的图片数据。
- 评分 JSON 缺字段或分数非法时可重试；部分评审失败时明确展示未完成成员，不再显示为全员完成。

验证：本地前端 97 项、Rust 单元及离线 HTTP 协议 42 项通过，Android 安装与固定签名回归通过。Android 实机通过约 5 分 39 秒连续锁屏测试：图片响应延迟 330 秒，主对话和两位评审首次连接主动中断，电脑 ADB 全程断开；生图、重试、评审及最终汇总均在屏幕关闭时完成，Goal 95 分通过且只有一份评审面板。该测试使用局域网模拟网关，未验证小时级锁屏或真实付费接口。

发布产物由 GitHub Actions 构建和验收，提供 Windows x64 免安装 EXE、NSIS 安装包、Android arm64-v8a APK，以及 `SHA256SUMS` 和固定 Android 证书指纹。Android 沿用 v0.2.9 的应用 ID 与固定证书，可覆盖升级并保留应用数据。
