新增主题切换、按会话保存的 Goal 自动修正，以及由 Chat 决定的生图失败重试和模型切换。

- 主题支持明亮、深色和跟随系统，顶部可快捷切换，设置页也可直接选择。明亮主题采用奶白、薄荷绿与青色；对话、代码块、模型列表、图库、预览和提示消息同步适配。
- 主题选择写入本机配置，启动时提前应用缓存；跟随系统会响应系统外观变化，手动选择不受系统切换影响。Android 同步状态栏、导航栏及安全区域背景，保存模式以便重启时继续遵守系统或手动选择。
- 每个会话新增默认关闭的“Goal 自动修正”开关，提供宽松、标准、严格三个验收等级，可设置最多修正 0–20 次。等级默认分别为 1、3、6 次。运行中的设置保持快照，其他会话独立运行。
- Goal 要求 Chat 检查实际最新最终成图，逐项列出要求、是否通过及依据；不满足时自动继续修正，达标、遇到不能解决的障碍、达到上限或用户停止时结束。验收、调用次数、修正次数和停止原因保存在会话中，文字任务保留完整最终答案。
- Goal 拒绝未知图片 ID、以旧图代替最新图、未通过项却判定达标，以及生图失败却声称图像完成。图像调用和对话轮次另设保护上限，用户可随时停止。
- 生图工具失败后把错误与失败调用 ID 交回 Chat，由 Chat 决定重试同一模型、换用模型池内其他模型或结束。重试工具保留实际素材及顺序、完整发送指令、尺寸、数量和输出参数；会话固定模型时不能擅自切换。
- 失败信息反馈给 Chat 前隐藏连接密钥和地址；重试记录展示实际使用模型、原失败调用、输入顺序与尺寸。本版本不增加备用 Chat 模型池。

验证：37 项前端回归、19 项 Rust 单元/协议测试和 31 项 Android 工程检查通过。桌面及 Android 尺寸的浏览器环境验证主题切换、系统跟随、重启保存、四个页面的宽度、Goal 设置及会话隔离。Goal 的生成→实际回图验收→修正→再次验收→结束，以及失败后重试/切换，经过离线完整工作流测试；新 Goal 流程尚未通过付费模型实测。

自动修正和重试会产生额外模型调用；次数上限和停止按钮可控制执行范围。验收依赖 Chat 模型的工具调用和视觉能力，图像组合/修正模型需要具备相应参考图能力。
