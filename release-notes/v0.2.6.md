本版加入软件更新检查、Goal 分数制验收、生图画质/分辨率选项、Android 后台稳定性修复与现代码固定签名发布。

- 「设置 → 软件更新」可检查本仓库 GitHub 最新 Release，显示版本、说明、发布时间和资产大小，并通过系统浏览器下载。仅接受本仓库的 Release 与资产地址，不会在应用内静默下载或安装未知文件。
- Goal 验收改为 0–100 分制，默认达标线 85。评分来源可选自动、评审团或 Chat；最终平均分达到阈值且全部明确约束通过后才会结束，修正次数范围为 0–20。
- Chat 生图支持 `quality`（`auto` / `low` / `medium` / `high` / `standard` / `hd`）与 `image_size`（`auto` / `1K` / `2K` / `4K`），参数会随请求发送并在重试时保留。
- 修复部分 Gemini 兼容网关把图片放在 `parts[].text` 的 Markdown data URL 中时无法识别的问题，单轮与多轮图片回复均可正确落盘和预览。
- 隐藏普通聊天与 Goal 中的空助手气泡；流式回复按 50ms 批量刷新，历史记录分页加载、图片懒加载，关闭面板及时卸载，降低 Android 端卡顿与无效渲染。
- Android 使用前台服务与可续期 Wake Lock，并增加启动就绪握手；后台中断时暂停队列，不自动重放可能产生费用的请求。
- Release 固定为 Windows x86_64 免安装 EXE / NSIS 安装包，以及 Android arm64-v8a APK。发布同时提供 `SHA256SUMS` 和公开证书指纹 `ANDROID_SIGNING_CERT_SHA256`。

**Android 升级注意**：v0.2.5 及更早版本使用临时 CI 证书，与本版固定证书不同，无法直接覆盖安装。请先备份/导出本地配置与数据，再卸载旧版并安装 v0.2.6；卸载会清除应用私有数据。完成这一次迁移后，后续版本只要保持同一应用 ID 与固定证书即可覆盖升级。

验证：83 项前端回归、13 项 Release 文件/脚本回归、7 项更新检查隔离回归和 Android 静态工程检查通过，TypeScript 与生产构建通过；Chrome 320 / 390 px 移动端模拟通过。Gemini 图片协议完成 3 轮真实付费联调，红/绿茶壶与黄星多轮编辑均成功。本机完整 Cargo 测试因页面文件不足（`os error 1455`）未跑完，Windows 安装版和 Android 真机尚未验收。
