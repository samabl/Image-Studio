支持多个生图模型分工与最终合成，更新清新明亮的应用图标。

- 设置页新增可多选的 Chat 生图模型池，可从完整模型列表勾选或手动输入 ID。每个模型独立配置接口类型、用途说明、参考图能力，以及可选的服务地址和 API Key。
- 会话可以固定一个生图模型，也可以选择自动，让 Chat 在启用模型中选择。会话选择独立保存，运行中的请求保持自己的配置。
- 支持 A 生成人物、B 生成背景，再由 C 编辑/组合实际结果图。可在同一轮提交多个独立素材工具，工具执行后将所有实际图片反馈给 Chat，再推进有依赖的合成步骤。
- 工具区记录每一步的实际模型、接口类型、素材顺序、完整指令和中间/最终成图阶段。中间素材的指令会明确本次子任务，避免提前执行整体合成要求。
- 自动按模型 ID 和服务地址预判 Images、兼容 Chat 或 Gemini 原生接口，用户可逐模型覆盖。仅文生图的模型不会被提供给编辑工具；实际调用也会检查启用模型和参考图能力。
- 更新为通过用户提供的 test API 生成的奶白、薄荷绿、天蓝、暖黄应用图标；同步 Windows、Android、iOS 尺寸、应用内标识和 favicon。Android 使用独立前景/背景并在生成工程时自动同步。
- Android 返回键优先收起键盘、关闭大图预览/菜单和图库选择，再返回对话首页；首页两秒内再次返回才回到桌面，运行中的任务继续。
- Android 默认保存到系统相册 `Pictures/Image Studio`，保留“另存为”选目录。Android 10+ 使用 MediaStore，旧系统按需申请存储权限并登记媒体库，原图不压缩。
- Chat 可在生图、编辑和最终合成时指定输出尺寸。Images 传递宽高，Gemini/兼容 Chat 转换为比例和分辨率档位；显式 auto 由模型决定，省略时沿用用户设置。

验证：30 项前端回归、18 项 Rust 单元/协议测试、31 项 Android 工程检查通过。A → B → C → 回图检查通过离线完整工作流回归，三种图像协议通过本地 HTTP 路由验证；模型池多选、接口覆盖、独立连接、会话固定模型和移动端宽度通过浏览器交互检查。新图标使用 `gpt-image-2.5` 实际生成。

分工能力需要 Chat 模型支持工具调用，最终合成模型需要支持多张参考图片。模型 ID 只能用于预判网关协议，别名或自定义网关请手动覆盖接口类型。

Android APK 仍使用临时 CI 签名；从旧版升级前请备份数据并卸载旧版，卸载会清除应用数据。Android 安全区域、返回键、相册保存和锁屏任务尚未在真机验证。
