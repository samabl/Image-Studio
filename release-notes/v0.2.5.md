新增多模型评审团、内置 JavaScript 代码改图，并改进布局、发送流程与图库整理。

- 评审团可配置多个识图模型、独立连接和评审侧重点，各自看图提供意见，由 Chat 汇总吸收；Chat 也可参与独立评审。对话最终成图自动送审，中间素材不送审；支持对已有图片发起评审、取消任务和单个成员失败隔离。
- 在「设置 → 代码图像编辑」启用后，Chat 可使用内置 JavaScript 对实际图片裁剪、缩放、翻转、旋转、调色、叠加及绘制，返回 PNG。支持 1–4 张输入/输出，代码、日志和执行状态保留在对话中；结果可继续编辑、送审或用于 Goal 验收，无需安装 Python。
- 代码在独立的 opaque-origin iframe 和 Worker 中运行，不开放网络、文件或应用接口；支持停止及 1–30 秒超时限制，图片边长最多 4096。SDK 有累计像素预算，但无法硬限制任意 JavaScript 堆分配，请仅为可信模型开启。
- 对话支持 FIFO 排队发送、暂停和管理队列；插话会停止当前任务、保留已收到的部分回复，并优先于队列发送。Enter 排队，Ctrl / ⌘ + Enter 插话；停止或重启不会自动恢复付费请求。
- 图片不再自动进入图库。过程图单独保存，仅点击「加入图库」的图片进入图库；不会自动清理已有图库或过程文件。
- 导航、设置和次要操作采用分层、可折叠布局，精简提示。小屏生成结果直接显示在编辑区下方，无需切换页，也不会以常驻结果栏遮挡主体。
- 图片预览支持按钮、滚轮和双指缩放、拖动及键盘操作；Android 返回键优先关闭预览和展开面板。Goal 修正次数支持清空后重填，失焦或 Enter 时才校验。

验证：67 项前端回归、12 项 Rust 单元测试、16 项协议测试及 Android 工程脚本通过，类型检查与生产构建通过。浏览器验证了移动端布局、发送顺序、手动入库、缩放和运行时隔离；通过 test API 跑通了 Chat 写代码、实际 PNG 像素验证、多模型评审和 Chat 汇总。Android 真机和已安装的 Windows 原生版本尚未验收。

评审团和代码改图默认关闭；每位评审会增加模型请求，并向其配置的服务发送图片。代码处理本身不调用生图 API，但 Chat 和评审仍有模型费用。
