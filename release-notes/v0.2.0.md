支持多协议、多图素材和并发会话的图像工作台更新。

- 模型列表支持独立搜索并显示全部返回模型，修复只能选择 GPT 模型的问题。
- 新增原生 Anthropic Messages、Gemini GenerateContent 协议；保留 OpenAI Chat Completions、Images 和兼容网关支持。
- 多张素材显示编号并可重排；对话工具可按图片 ID 指定输入顺序，编辑和提示词优化会读取全部选定素材。
- 优化提示词时保留原始要求，加强文字、数量、构图和禁止项的遵循。
- 多个会话可同时运行，草稿、流式响应、后台状态与取消操作各自独立。
- 对话、图库、工作室和大图预览均可保存图片到用户选择的位置。
- 增加前端及协议回归测试，版本 tag 构建通过后自动发布安装包和 SHA256 校验和。

下载：Windows x64 提供免安装 EXE 和安装包；Android 提供 arm64-v8a、armeabi-v7a、x86_64 的已签名 APK。普通 Android 手机优先选择 arm64-v8a。

验证：14 项前端回归、2 项 Rust 单元测试、12 项协议回归通过。真实网关已通过对话、工具调用、OpenAI Images 生成/编辑/蒙版及多图输入联调；原生 Anthropic/Gemini 已验证双图顺序和工具调用。

已知限制：本次测试网关的 Gemini 原生出图返回上游 429/404，未验证成功；Android 保存功能尚未在真机验证。当前 CI 未配置固定 Android 签名密钥，APK 使用临时签名，升级旧版时需先卸载；卸载会清除应用数据，请先备份。
