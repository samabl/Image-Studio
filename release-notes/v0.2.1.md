修复对话生图、回图检查时的卡死/白屏，以及 Android 顶部内容被状态栏遮挡。

- 修复 Markdown 粗体/斜体递归渲染共用正则匹配位置的问题。旧版会无限重复相同文字并耗尽内存，Windows 可能白屏卡住，Android 可能退出。
- 增加生图说明、回图检查、嵌套格式、列表/表格及逐字流式输出的渲染回归，用子进程超时保护防止测试本身卡死。

- 浏览器/iOS 页面和大图预览补齐 CSS 安全区域间距。
- 选择模型后自动收起列表并清空搜索，下次打开仍显示全部模型。
- Android 对话、生图、提示词优化及回图检查使用带通知的前台任务服务和唤醒锁，完整工作流共用一个任务，并发会话独立计数，完成或取消后释放。设置页新增电池优化和通知授权入口，用于锁屏后继续运行。

验证：17 项前端回归、14 项 Rust 单元/协议测试、29 项 Android 工程安装检查通过。真实网关已通过 `gpt-6.1-sol → gpt-image-2.5 → 回图检查` 闭环；实际模型回复在浏览器完成渲染，模型列表选中即收起、再次打开清空搜索已通过交互验证。
